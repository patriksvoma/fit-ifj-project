\section{Spolupráce na projektu} {
  Pro spolupráci na projektu jsme využili GitHub, pro komunikaci Discord, případně osobní setkání.
  Stanovili jsme si pravidla ohledně formátování, pojmenovávání proměnných či funkcí, nebo commitů.
  Do CI pipeline jsme zapojili kontroly pomocí \texttt{clang-format} a \texttt{cppcheck}.
  Pro vynucení dodržování pravidel jsme uzamknuli branch \texttt{main} a využili GitHub Actions, kde se testy automaticky spouští a pro schválení PR je vyžadováno, aby byly úspěšné.
  \par
  Pro formátování kódu jsme využili vestavěný styl \texttt{Microsoft} s odsazením tabulátory. Pro další automatické nastavení jsme využili soubor \texttt{.editorconfig}.
 }

  \subsection{Syntaktická analýza} {
	  Syntaktický analyzátor se řídí metodou rekurzivního sestupu a pro zpracování výrazů předává řízení precedenčnímu analyzátoru.
	  Každé pravidlo má v \texttt{parser.c} vlastní funkci, která provádí syntaktické kontroly, případně tvoří abstraktní syntaktický strom.
	  Funkce si předávají data strukturou \texttt{compiler\_data\_t cdata}. Při vstupu do bloku je vždy vytvořena nová tabulka symbolů, při výstupu ale není zničena.
	  Tabulky symbolů jsou zničeny naráz až po sémantické analýze.
	  \par
	  Precedenční analýza se řídí podle precedenční tabulky, v případě že narazí na volání funkce nebo na podmíněný výraz if, zpracuje ho jako celek a poté teprve pokračuje.

  \subsection{Sémantická analýza} {
	  Většina sémantických kontrol je prováděna až po syntaktické analýze, a to postorder průchodem abstraktního syntaktického stromu (Výjimku tvoří například kontrola redefinice funkcí či proměnných, která ji prováděna při syntaktické analýze).
	  Tento přístup jsme zvolili, protože ve chvíli kdy se provádí sémantické kontroly jsou již definované všechny funkce.
	  \par
	  Při průchodu se pro každý uzel stromu nastavuje typ vyhodnocení \texttt{eval\_type}, pomocí kterého se provádějí typové kontroly.
	  Při kontrole typu může sémantický analyzátor vkládat do stromu uzly pro převod z typu \texttt{Int} na typ \texttt{Double}.
